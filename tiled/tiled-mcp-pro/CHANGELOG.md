# Changelog

All notable changes to Tiled MCP Pro will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-03-31

### Added

- Initial release
- 122 tools across 12 categories
- Map management (create, open, save, resize, export)
- Layer management (tile, object, image, group)
- Tile operations (place, fill, stamp, replace)
- Tileset management (create, import, collection)
- Object tools (rectangle, ellipse, polygon, polyline, text, tile)
- Custom property management
- Wang/Terrain set support
- Editor control tools
- Project & world tools
- Image manipulation
- Export in multiple formats
- Map analysis & validation
- Bridge-based communication (Node.js WebSocket <-> Tiled extension)
