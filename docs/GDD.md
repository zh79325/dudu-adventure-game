## 1. 游戏概述

### 基本信息

| 项目 | 内容 |
|------|------|
| **游戏名称** | 都都大冒险 |
| **类型** | 2D 横版动作 / 副本刷宝（DNF 式） |
| **联机形态** | 本地同屏合作（一台设备多手柄），最多 4 人 |
| **目标平台** | 平板电脑（iPad / Android Tablet）+ Xbox 主机 |
| **美术风格** | 像素风（Pixel Art），32×32 基础网格 |
| **目标受众** | 8-35 岁，喜欢西游记题材、刷装备和本地合作游戏的休闲至中度玩家 |
| **单次副本时长** | 5-15 分钟 |
| **开发规模** | 单人开发（初学者），渐进式交付 |

### 一句话介绍（Elevator Pitch）

> 最多四名玩家各选一位西游角色（悟空、八戒、沙僧、唐僧），在随机拼接的像素副本里并肩刷怪、打 Boss、爆装备——操作简单、爽快打击感、沙发上就能一起玩。

### 核心卖点

- **本地同屏合作：** 插手柄按 Start 即加入，最多 4 人沙发合作，无需网络
- **刷宝驱动：** 装备五档稀有度 + 随机词条，每次副本都有新收获
- **经典西游新演绎：** 花果山、天宫、火焰山……像素风格重新呈现，老少皆宜
- **四角色各有所长：** 悟空七十二变、八戒下耙、沙僧横扫、唐僧佛光——各一个标志大招
- **随机副本：** 手工房间模块 + 随机拼接，每次路线不同，高重玩性
- **初学者友好：** 操作简单易上手，难度随人数 + 装备等级动态缩放

### 设计参考

| 参考作品 | 借鉴要素 |
|---------|---------|
| **《地下城与勇士》（DNF）** | 2D 横版副本结构、清场开门、逐房推进 |
| **《我的世界：地下城》（Minecraft Dungeons）** | 装备驱动成长、本地合作、难度缩放 |
| **《胡闹厨房》（Overcooked）** | 沙发合作的轻松氛围、按键即加入 |

## 2. 故事背景

### 故事大纲

故事取材自中国古典名著《西游记》，针对游戏叙事做了简化和改编。副本的场景和 Boss 均取自西游经典桥段，但叙事是**碎片化**的——通过副本主题、Boss 对话、装备描述来讲故事，而非线性章节。

#### 世界观设定

天地之间妖魔横行，师徒四人踏上取经之路。每座山、每条河都是一个"副本"——进去时不知道里面有什么妖怪，打通才能继续西行。收集到的装备是路上缴获的妖怪法宝，越稀有越强力。

#### 剧情传达方式

- **副本主题：** 每种副本对应一段西游故事（花果山、天宫、白骨岭、火焰山等）
- **Boss 对白：** Boss 战前后各一句台词，交代前因后果
- **装备描述：** 传说级装备自带一小段西游典故（如"定海神针——龙宫镇海之宝，重一万三千五百斤"）
- **环境叙事：** 通过背景、场景细节暗示剧情

### 叙事原则

- **对话从简：** 每段对话不超过 3 句，用像素动画表情代替长篇文字
- **演出优先：** 重要剧情用简短的过场动画，而非文字描述
- **不阻碍节奏：** 任何叙事均可跳过，绝不强制等待

## 3. 核心玩法

### 核心循环（Core Loop）

```
选角色 → 进副本 → 逐房清怪 → 打 Boss → 爆装备 → 换更好的装备 → 挑战更高难度
```

副本内的微循环：

```
进入房间 → 门关闭 → 清场所有怪物 → 门打开 → 拾取掉落 → 进入下一房间
```

### 3.1 移动与跳跃

| 操作 | 说明 |
|------|------|
| **基础移动** | 左右方向移动 |
| **普通跳跃** | 单次跳跃，高度固定 |
| **冲刺** | 快速闪避，附带短暂无敌帧（0.3 秒），冷却 1.5 秒 |
| **攀墙** | 贴墙后短暂停留并可以蹬墙跳 |

> 注：二段跳和筋斗云滑翔在 v1.0 中取消，改为角色大招提供机动性差异。

### 3.2 战斗系统

#### 通用攻击

| 攻击方式 | 说明 | 伤害倍率 |
|---------|------|---------|
| **轻攻击** | 快速挥击，连按可打出 3 连击 | ×1.0 / ×1.0 / ×1.5 |
| **重攻击** | 蓄力后大力一击，可击飞敌人 | ×2.5（满蓄力） |
| **下砸攻击** | 空中按下+攻击，从天而降砸击 | ×2.0 |

#### 角色大招（阶段 4 实现）

每个角色各拥有一个标志性大招，带独立冷却或能量条。详见第 4 节角色设计。

#### 战斗手感要点

- **打击反馈：** 击中瞬间画面短暂停顿（Hit Stop）0.05-0.1 秒
- **击退效果：** 敌人被击中后有明显击退动画
- **屏幕震动：** 重攻击命中时屏幕轻微震动
- **粒子特效：** 击中时产生星星/火花粒子
- **连击计数：** 屏幕角落显示当前连击数，影响掉落品质权重

### 3.3 装备系统（阶段 2 实现）

#### 属性

`CharacterStats` 涵盖：血量、攻击、防御、攻速、移速、暴击率、暴击伤害。每个角色有基础值，装备提供增量。

#### 装备模板与词条

- 装备以 ScriptableObject 为模板，运行时 roll 随机词条
- 同一模板每次掉落可能不同属性——这是"刷"的动力
- 词条示例：攻击+12、暴击率+5%、击杀回血 2%……

#### 稀有度五档

| 稀有度 | 颜色 | 词条数量 | 掉率权重 |
|--------|------|---------|---------|
| 普通 | 白色 | 0-1 | 高 |
| 精良 | 绿色 | 1-2 | 中 |
| 稀有 | 蓝色 | 2-3 | 低 |
| 史诗 | 紫色 | 3-4 | 极低 |
| 传说 | 橙色 | 4（含固定特殊词条） | Boss 保底 |

#### 掉落规则

- 普通怪按 `LootTable` 权重掉落
- Boss 有保底：每次击杀至少掉一件稀有或以上品质
- 难度越高，基础掉率权重向高稀有度偏移
- 多人模式下各人独立掉落（不抢装）

### 3.4 生命值与受伤机制

- **生命值（HP）：** 由 `HealthComponent` 管理，基础值来自 `CharacterStats`
- **队伍共享生命池：** 全队共享总血量上限，任何人受伤扣的是同一池——鼓励互相保护
- **受伤反馈：** 角色闪烁 + 短暂无敌（1 秒）
- **倒地与复活：** 单人 HP 归零则倒地，队友可在旁按键复活；全灭则副本失败
- **难度缩放：** 怪物属性随人数增加而提升，保证 1-4 人体验平衡

## 4. 角色设计

### 设计原则

四个角色**全部可玩**（不是 NPC 辅助），不允许重复选择。每角色共享基础操作（移动/跳/攻击/冲刺），但拥有一个**标志性大招**和略有差异的基础属性倾向。

### 4.1 孙悟空（悟空）

| 项目 | 内容 |
|------|------|
| **定位** | 全能近战 / 灵活 |
| **属性倾向** | 攻速高、移速快、HP 中等 |
| **大招：七十二变** | 短暂变身增强形态（攻击力翻倍 + 攻击范围增大），持续数秒 |
| **灰盒颜色** | 金色 `(1, 0.75, 0.3)` |

**像素外观（最终版）：** 32×32，金黄色毛发，红色披风，手持金箍棒，头戴金箍。

### 4.2 猪八戒（八戒）

| 项目 | 内容 |
|------|------|
| **定位** | 重击坦克 / 高伤害 |
| **属性倾向** | 攻击高、HP 高、移速慢 |
| **大招：下耙** | 九齿钉耙重砸地面，前方扇形范围巨大伤害 + 击飞 |
| **灰盒颜色** | 粉色 `(1, 0.62, 0.78)` |

**像素外观（最终版）：** 32×32，圆滚滚身体，猪鼻子，扛着九齿钉耙。

### 4.3 沙僧（沙僧）

| 项目 | 内容 |
|------|------|
| **定位** | 范围控场 / 稳健 |
| **属性倾向** | 防御高、HP 高、攻速中等 |
| **大招：长柄横扫** | 降妖宝杖 360° 横扫，大范围击退 + 眩晕 |
| **灰盒颜色** | 蓝色 `(0.45, 0.72, 1)` |

**像素外观（最终版）：** 32×32，蓝色衣服，挂佛珠，持降妖宝杖。

### 4.4 唐僧（唐僧）

| 项目 | 内容 |
|------|------|
| **定位** | 辅助 / 治疗 |
| **属性倾向** | HP 最高、攻击最低、有治疗效果 |
| **大招：佛光普照** | 全屏金光，治疗所有队友 + 对周围敌人造成圣伤害 |
| **灰盒颜色** | 淡金 `(1, 0.95, 0.75)` |

**像素外观（最终版）：** 32×32，白色僧袍，光头，手持锡杖。

### 4.5 敌人体系

#### 敌人分级

```
普通小妖（1-2 击击杀）
    ↓
精英怪（5-8 击，有特殊技能）
    ↓
副本 BOSS（多阶段，属性随难度缩放）
```

#### 普通敌人

| 敌人 | 出现副本 | 行为模式 |
|------|---------|---------|
| **小妖兵** | 所有 | 来回巡逻，发现玩家后追击 |
| **弓箭妖** | 天宫、白骨岭 | 站在高处远程射箭 |
| **石头怪** | 五指山 | 缓慢移动，正面免疫（需绕后） |
| **蝙蝠妖** | 白骨岭 | 空中飞行，俯冲攻击 |
| **火妖** | 火焰山 | 投掷火球，地面留火 |

#### 精英怪

| 精英怪 | 出现副本 | 特殊机制 |
|--------|---------|---------|
| **黑熊精** | 花果山 | 格挡正面攻击，需绕后或反击 |
| **白骨精化身** | 白骨岭 | 伪装成物品，靠近突然攻击 |
| **铁扇公主** | 火焰山 | 芭蕉扇吹风推人，需找掩体 |

#### Boss

| Boss | 所属副本 | 阶段数 | 设计重点 |
|------|---------|--------|---------|
| **混世魔王** | 花果山 | 1 | 教学 Boss，观察→躲避→反击 |
| **巨灵神** | 天宫 | 1 | 范围攻击教学，跳跃躲避 |
| **白骨精** | 白骨岭 | 3 | 三变机制，识别真身 |
| **红孩儿** | 火焰山 | 2 | 环境互动（水池灭火） |
| **牛魔王** | 火焰山深处 | 3 | 综合考验，狂暴阶段 |

敌人索敌机制：周期性锁定最近的存活玩家，Boss 可覆盖为特殊仇恨逻辑（如"永远锁唐僧"）。

## 5. 副本与关卡设计

### 整体结构

游戏不再是线性章节推进，而是**副本选择**模式：

```
大地图（选副本入口） → 进入副本 → 随机拼接 5 个房间 → 第 5 间为 Boss 房 → 通关回到大地图
```

副本以西游场景为主题，每个主题对应不同的地图块（Tile）、敌人组合和 Boss：

| 副本主题 | 对应西游故事 | 环境特色 | Boss |
|---------|------------|---------|------|
| **花果山** | 石猴出世 | 翠绿树林、瀑布、水帘洞 | 混世魔王 |
| **天宫** | 大闹天宫 | 金色殿宇、云彩、仙鹤 | 巨灵神 |
| **白骨岭** | 三打白骨精 | 枯树林、雾气、破败村庄 | 白骨精 |
| **火焰山** | 借芭蕉扇 | 红橙岩浆、黑色岩石 | 牛魔王 |

### 房间模块化设计（阶段 3 实现）

- 每个副本主题有 10-15 个手工设计的房间模块预制体
- 每个房间有标准的左/右进出口锚点
- 拼接器按权重选房间、对齐锚点、保证可通行
- **清场门（DNF 式）：** 房间内敌人全灭才解锁出口
- **刷怪器与波次：** 每房间 1-3 波怪，波与波之间有短暂喘息
- **Boss 房保底掉落：** 至少一件稀有品质以上装备
- **难度档位：** 普通 / 困难 / 地狱，缩放怪物属性与掉落品质

### 房间类型

| 类型 | 说明 |
|------|------|
| **战斗房** | 标准清怪，1-3 波 |
| **精英房** | 含一个精英怪 + 少量小怪，掉落加成 |
| **宝箱房** | 无敌人，但有陷阱/解谜才能开箱 |
| **Boss 房** | 最终房间，Boss 战 + 保底掉落 |
| **休息房** | 罕见出现，提供治疗泉水，让队伍回血 |

### 关卡设计原则

1. **节奏曲线：** 每副本遵循"简单房→中等房→精英/宝箱→困难房→Boss"的强度爬升
2. **随机但不混乱：** 房间池按难度标签分类，拼接器保证前松后紧
3. **多人空间：** 每个房间至少 2 屏宽，确保 4 人不拥挤
4. **环境特色：** 不同副本主题的房间有独特机关（如火焰山的岩浆地面、天宫的云平台）

## 6. 操作系统

### 6.1 多人输入架构

游戏使用自定义输入抽象层（`IPlayerInputSource`），每个玩家实例绑定独立的输入设备。不使用 Unity 官方 `PlayerInputManager`，改为 `PlayerJoinManager` 自行轮询设备加入/退出。

**加入方式：**
- 键盘自动作为 1P 加入
- 手柄按 **Start** 加入
- 手柄按 **Select/Back** 退出
- 最多 4 人，角色不可重复

### 6.2 手柄控制（Xbox / 通用 Gamepad）

| 按键 | 功能 |
|------|------|
| **左摇杆 / 十字键** | 移动 |
| **A 键（buttonSouth）** | 跳跃 |
| **X 键（buttonWest）** | 攻击 |
| **B 键（buttonEast） / RB** | 冲刺/闪避 |
| **Y 键（buttonNorth）** | 大招（阶段 4） |
| **Start** | 加入游戏 / 暂停 |
| **Select/Back** | 退出游戏 |

### 6.3 键盘控制（1P 调试 / 单人）

| 按键 | 功能 |
|------|------|
| **A / D 或 方向键** | 移动 |
| **空格** | 跳跃 |
| **J** | 攻击 |
| **K 或 左Shift** | 冲刺/闪避 |
| **L** | 大招（阶段 4） |
| **Escape** | 暂停 |
| **Enter** | 加入游戏（第二键盘玩家，如有） |

### 6.4 平板触屏控制（未来实现）

采用虚拟摇杆 + 按钮布局，适配横屏模式。触屏模式下为单人体验（平板本地多人不现实）。

| 按钮 | 位置 | 功能 |
|------|------|------|
| **虚拟摇杆** | 左下角 | 移动方向 |
| **A 按钮** | 右下角 | 跳跃 |
| **B 按钮** | A 上方 | 攻击 |
| **C 按钮** | A 左侧 | 冲刺/闪避 |
| **大招按钮** | B 右侧 | 大招 |
| **暂停** | 左上角 | 暂停菜单 |

### 6.5 镜头与多人视角

- **固定缩放，跟随队长：** 镜头始终跟随 1P（队长），不做动态缩放
- **队长规则：** 第一个加入的玩家为队长；队长退出时自动移交给下一个存活玩家
- **掉队处理：** 非队长离开视口边缘 0.6 秒后自动传送到队长身边
- **Pixel Perfect 兼容：** 固定缩放不与 Pixel Perfect Camera 的 `orthographicSize` 覆写冲突

## 7. 美术方向

### 7.1 像素风格指南

**基础规格：**
- **基础网格：** 32×32 像素（角色和道具）
- **地图块（Tile）：** 32×32 像素
- **分辨率：** 游戏内部分辨率 480×270（16:9），按整数倍放大到目标屏幕
- **放大倍率：** 平板上 4-5 倍，Xbox 1080p 下 4 倍

**风格原则：**
- **清晰可读：** 角色和背景色彩对比明显，4 个玩家角色在乱战中仍可一眼分辨
- **有限调色板：** 每个副本主题使用 16-24 色调色板，保持视觉统一
- **避免抖动：** 不使用亚像素动画，所有移动以整像素为单位
- **参考风格：** Celeste（精致感） + 东方题材色彩

### 7.2 各副本主题配色方案

#### 花果山


## 8. 音效音乐

### 8.1 音乐方向

**整体风格：** 芯片音乐（Chiptune） + 中国民族乐器采样（笛子、古筝、二胡）

| 场景类型 | 音乐风格 | 乐器重点 | 情绪 |
|---------|---------|---------|------|
| **主菜单** | 悠扬的笛子旋律 + 轻快节拍 | 笛子 + 8-bit 鼓点 | 期待、冒险 |
| **副本探索** | 轻快的 8-bit 旋律 | 古筝 + Chiptune | 轻松、前进感 |
| **战斗（普通房）** | 快节奏鼓点 + 激昂旋律 | 鼓 + 电吉他音色 | 紧张、热血 |
| **Boss 战** | 史诗感 + 快速节奏 | 二胡 + 重金属节拍 | 压迫感、挑战 |
| **胜利结算** | 欢快、庆祝感 | 全乐器合奏 | 成就、喜悦 |
| **副本失败** | 缓慢、低沉 | 古筝独奏 | 惋惜但不沉重 |

**音乐技术要点：**
- 使用循环音乐（Loop），每首 1-2 分钟循环
- Boss 战音乐有"阶段切换"变奏（HP 低于 50% 时加入更激烈的层次）
- 总曲目数：8-12 首（含变奏）

### 8.2 音效设计

#### 角色音效

| 音效 | 描述 | 时长 |
|------|------|------|
| 跳跃 | 轻快的"嗖"声 | 0.2s |
| 轻攻击 | 武器挥动的"呼呼"声 | 0.3s |
| 重攻击 | 蓄力"嗡"声 + 猛烈挥击 | 0.8s |
| 受伤 | 角色痛呼（像素风处理） | 0.4s |
| 冲刺 | 快速移动的"嗖嗖"声 | 0.3s |
| 大招释放 | 角色专属音效 + 能量爆发 | 1.0-1.5s |
| 装备掉落 | 品质越高音效越华丽 | 0.3-0.8s |

#### 环境音效

#### UI 音效

| 音效 | 触发时机 |
|------|---------|

| 副本通关 | 打败 Boss 后 |

### 8.3 音频资源建议

- **音乐制作：** 使用 FamiTracker 或 LMMS 制作 8-bit 风格音乐
- **音效制作：** 使用 Bfxr 或 sfxr 生成 8-bit 音效
- **免费资源：** 可参考 freesound.org、OpenGameArt.org
- **格式：** 音乐使用 OGG Vorbis，音效使用 WAV（短音效）或 OGG（长音效）
- **音量分层：** 音乐 60%、音效 80%、环境音 40%（可在设置中调节）

## 9. 开发路线图

### 整体策略

采用**分阶交付**策略，每个阶段都以"能玩到"为验收标准。详细的技术实施计划见 [DUNGEON_COOP.md](DUNGEON_COOP.md)。

### 阶段 1：多人基础 ✅ 已完成

**验收标准：** 两个手柄能同时在灰盒场景里跑跳，镜头跟队长，掉队会被拉回来。

已实现：输入抽象层、玩家注册表与队长系统、镜头跟随队长、离屏传送、4 人动态加入/退出、四角色灰盒 Prefab、敌人锁定最近活人。

### 阶段 2：装备与属性（进行中）

**验收标准：** 打死一只怪掉出一把橙武，捡起来伤害数字变大。

关键系统：`CharacterStats`、装备模板 SO + 运行时词条随机、五档稀有度、`LootTable`、属性聚合、`DamageDealer` 读属性。

### 阶段 3：副本结构

**验收标准：** 随机拼出一个五房间副本，清场才开门，最后一间是 Boss，通关给奖励。

关键系统：房间模块预制体 + 锚点、拼接器、清场门、刷怪波次、Boss 房保底掉落、难度缩放。

### 阶段 4：角色大招

**验收标准：** 四个标志性大招各带冷却或能量条——悟空七十二变、八戒下耙、沙僧横扫、唐僧佛光。

### 后续：美术替换 + 打磨 + 发布

- 替换灰盒方块为正式像素 Sprite + 动画
- 添加所有背景音乐和音效
- 副本选择大地图 UI
- 平板触屏虚拟按键
- 平衡性调整
- Xbox 平台认证 / App Store 上架

### B. 术语表

| 术语 | 解释 |
|------|------|
| **Hit Stop** | 击中瞬间的短暂停顿，增强打击感 |
| **i-frame** | 无敌帧，受伤后的短暂无敌时间 |
| **Tile** | 地图块，用于拼接关卡地图的基础图片单元 |
| **清场门** | DNF 式设计：房间内敌人全灭才能开门进入下一房间 |
| **词条** | 装备上的随机属性加成，如"攻击+12" |
| **保底** | Boss 击杀必掉一件稀有以上品质装备的机制 |
| **Coyote Time** | 土狼时间，离开平台边缘后仍可跳跃的宽容时间（0.1 秒） |
| **Jump Buffer** | 跳跃缓冲，落地前按跳跃键会在落地瞬间自动跳跃（0.1 秒） |
