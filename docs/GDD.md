## 1. 游戏概述

### 基本信息

| 项目 | 内容 |
|------|------|
| **游戏名称** | 都都大冒险 |
| **类型** | 2D 横版动作/平台跳跃 |
| **目标平台** | 平板电脑（iPad / Android Tablet）+ Xbox 主机 |
| **美术风格** | 像素风（Pixel Art），32×32 基础网格 |
| **目标受众** | 8-35 岁，喜欢西游记题材和动作游戏的休闲至中度玩家 |
| **游戏时长** | 主线约 4-6 小时（含收集要素可达 8 小时） |
| **开发规模** | 单人开发（初学者），预计 12-18 个月完成 |

### 一句话介绍（Elevator Pitch）

> 扮演齐天大圣孙悟空，在精美的像素世界中挥舞金箍棒、腾云驾雾，重走西游之路，降妖除魔！简单的操作，畅快的打击感，适合平板触屏和手柄双端体验。

### 核心卖点

- **经典题材新演绎：** 西游记故事以像素风格重新呈现，老少皆宜
- **双端操作：** 平板触屏 + Xbox 手柄，同一套游戏逻辑，两种操作体验
- **变身系统：** 孙悟空七十二变，解锁不同形态应对不同场景
- **逐步解锁同伴：** 唐僧、猪八戒、沙僧依次加入，每人提供独特辅助能力
- **初学者友好：** 关卡难度平滑上升，操作简单易上手

## 2. 故事背景

### 故事大纲

故事取材自中国古典名著《西游记》，针对游戏叙事做了简化和改编。

#### 序幕：石猴出世

天地之间，花果山上一块仙石迸裂，诞生一只石猴——都都（孙悟空）。他天赋异禀，成为花果山猴王，日子无忧无虑。

> **游戏映射：** 第 1 章教学关卡，玩家在花果山自由探索，学习基础操作。

#### 第一幕：大闹天宫

都都本领渐强，上天入地无所不能。他闯入龙宫取得如意金箍棒，又因不服天庭管束，大闹天宫。最终被如来佛祖压在五指山下五百年。

> **游戏映射：** 第 2 章战斗教学 + 第 3 章过渡剧情。这段以回忆/闪回形式呈现。

#### 第二幕：踏上取经路

五百年后，唐僧路过五指山，揭下封印救出都都。都都感恩戴德，誓保唐僧西天取经。一路上先后收服猪八戒和沙僧，四人结伴西行。

> **游戏映射：** 同伴系统逐步解锁，每收服一个同伴解锁新能力。

#### 第三幕：降妖除魔

取经路上妖怪横行，各怀鬼胎想吃唐僧肉以求长生。都都火眼金睛识破妖怪变化，金箍棒下绝不姑息。

> **游戏映射：** 第 4 章起的核心玩法循环，每章一个经典妖怪 BOSS。

#### 尾声：取得真经

历经九九八十一难，师徒四人终于到达西天大雷音寺，取得真经，修成正果。

> **游戏映射：** 通关结局动画 + 隐藏挑战关卡。

### 叙事原则

- **对话从简：** 每段对话不超过 3 句，用像素动画表情代替长篇文字
- **环境叙事：** 通过背景、场景细节暗示剧情（如废墟暗示曾经的战斗）
- **演出优先：** 重要剧情用简短的过场动画，而非文字描述

## 3. 核心玩法

### 核心循环（Core Loop）

```
探索关卡 → 消灭小怪 → 收集道具 → 挑战 BOSS → 解锁新能力/同伴 → 进入下一章
```

每个关卡内部的微循环：

```
移动跳跃 → 发现敌人 → 战斗/躲避 → 获得奖励 → 到达存档点 → 推进剧情
```

### 3.1 移动与跳跃

| 操作 | 说明 |
|------|------|
| **基础移动** | 左右方向移动，支持 8 方向移动（上下坡） |
| **普通跳跃** | 单次跳跃，高度固定 |
| **二段跳** | 空中再跳一次（解锁筋斗云后获得） |
| **筋斗云跳跃** | 长按跳跃键召唤筋斗云，短暂滞空滑翔（最长 2 秒） |
| **冲刺** | 快速闪避，附带短暂无敌帧（0.3 秒），冷却 1.5 秒 |
| **攀墙** | 贴墙后短暂停留并可以蹬墙跳 |

### 3.2 战斗系统

#### 金箍棒攻击

| 攻击方式 | 说明 | 伤害倍率 |
|---------|------|---------|
| **轻攻击** | 快速挥棒，连按可打出 3 连击 | ×1.0 / ×1.0 / ×1.5 |
| **重攻击** | 蓄力后大力一棒，可击飞敌人 | ×2.5（满蓄力） |
| **下砸攻击** | 空中按下+攻击，从天而降砸击 | ×2.0 |
| **旋转攻击** | 金箍棒变长旋转，范围伤害 | ×1.5（群体伤害） |
| **变大攻击** | 金箍棒变大，攻击距离增加（消耗法力） | ×1.8 |

#### 战斗手感要点

- **打击反馈：** 击中瞬间画面短暂停顿（Hit Stop）0.05-0.1 秒
- **击退效果：** 敌人被击中后有明显击退动画
- **屏幕震动：** 重攻击命中时屏幕轻微震动
- **粒子特效：** 击中时产生星星/火花粒子
- **连击计数：** 屏幕角落显示当前连击数，影响掉落奖励

### 3.3 变身系统

都都可以变身成不同形态，每种形态有独特的移动方式和攻击手段：

| 形态 | 解锁条件 | 特殊能力 | 适用场景 |
|------|---------|---------|---------|
| **默认（猴王）** | 初始 | 金箍棒近战 | 通用 |
| **小鸟** | 第 2 章通关 | 飞行（限时 5 秒） | 到达高处平台 |
| **鱼儿** | 第 4 章通关 | 水中自由移动 | 水下关卡 |
| **巨人** | 第 5 章通关 | 攻击力翻倍，体型增大 | 对抗大型 BOSS |

**变身限制：** 每次变身消耗法力值（MP），变身持续 10 秒，冷却 15 秒。

### 3.4 道具与收集

#### 消耗品

| 道具 | 效果 | 获取方式 |
|------|------|---------|
| **蟠桃** | 恢复 30% 生命值 | 关卡内拾取、商店购买 |
| **仙丹** | 恢复全部法力值 | 关卡内宝箱 |
| **铜钱** | 通用货币 | 击败敌人掉落 |

#### 收集品

| 收集品 | 说明 | 收集奖励 |
|--------|------|---------|
| **经书碎片** | 每关隐藏 3 片，集齐解锁隐藏关卡 | 全部集齐 → 隐藏结局 |
| **猴子猴孙** | 被困在关卡中的小猴子，救出后跟随 | 每救 5 只 → 永久属性提升 |
| **妖怪图鉴** | 击败新敌人自动记录 | 全图鉴 → 解锁挑战模式 |

### 3.5 生命值与受伤机制

- **生命值（HP）：** 初始 5 颗心，每颗心可承受 1 次普通攻击伤害
- **法力值（MP）：** 初始 3 格，用于变身和特殊技能
- **受伤反馈：** 角色闪烁 + 短暂无敌（1 秒）
- **死亡：** 从最近存档点重新开始，不丢失已收集道具
- **难度调节：** 简单模式下每颗心可承受 2 次伤害

## 4. 角色设计

### 4.1 主角：都都（孙悟空）

**外观设计（像素风）：**
- 基础尺寸：32×32 像素
- 金黄色毛发，红色披风（标志性视觉元素）
- 头戴金箍（故事关键道具）
- 手持金箍棒（可大可小，攻击时有明显挥动轨迹）
- 表情丰富：待机时抓耳挠腮，战斗时目光炯炯

**动画帧数参考：**

| 动画 | 帧数 | 帧率 |
|------|------|------|
| 待机 | 4 帧 | 6 FPS |
| 跑步 | 8 帧 | 12 FPS |
| 跳跃（上升） | 3 帧 | — |
| 跳跃（下落） | 3 帧 | — |
| 轻攻击 | 6 帧 | 15 FPS |
| 重攻击 | 10 帧 | 12 FPS |
| 受伤 | 3 帧 | 10 FPS |
| 死亡 | 6 帧 | 8 FPS |

**性格表现：**
- 勇敢、好动、有点骄傲
- 通过动作表现性格（如idle动画中耍金箍棒、四处张望）
- 遇到强敌会露出兴奋表情而非恐惧

### 4.2 同伴 NPC

同伴不直接参与战斗（避免 AI 复杂度），而是提供**被动辅助能力**：

#### 唐僧

| 项目 | 内容 |
|------|------|
| **解锁时间** | 第 3 章开始 |
| **外观** | 白色僧袍，光头，手持锡杖 |
| **辅助能力** | 缓慢自动回复 HP（每秒回复 0.5%） |
| **对话风格** | 慈悲为怀，偶尔唠叨 |
| **游戏内表现** | 出现在关卡开头/结尾的过场中，提供故事推进 |

#### 猪八戒

| 项目 | 内容 |
|------|------|
| **解锁时间** | 第 4 章通关后 |
| **外观** | 圆滚滚身体，猪鼻子，扛着九齿钉耙 |
| **辅助能力** | 重攻击伤害 +50%，可破坏特定障碍物 |
| **对话风格** | 贪吃、偷懒、搞笑担当 |
| **游戏内表现** | 在关卡特定位置出现帮忙打开隐藏路径 |

#### 沙僧

| 项目 | 内容 |
|------|------|
| **解锁时间** | 第 5 章通关后 |
| **外观** | 蓝色衣服，挂佛珠，挑着担子 |
| **辅助能力** | 道具掉落率 +30%，增加存档点数量 |
| **对话风格** | 沉稳、忠诚、话不多但句句到位 |
| **游戏内表现** | 管理商店系统，可在存档点与其对话购物 |

### 4.3 敌人体系

#### 敌人分级

```
普通小妖（1-2 击击杀）
    ↓
精英怪（5-8 击，有特殊技能）
    ↓
关卡 BOSS（多阶段，30-50 击）
```

#### 普通敌人设计

| 敌人 | 出现章节 | 行为模式 | HP |
|------|---------|---------|-----|
| **小妖兵** | 第 1 章起 | 来回巡逻，发现玩家后追击 | 2 |
| **弓箭妖** | 第 2 章起 | 站在高处远程射箭，不会追击 | 2 |
| **石头怪** | 第 3 章起 | 缓慢移动，正面攻击无效（需从背后攻击） | 4 |
| **蝙蝠妖** | 第 4 章起 | 空中飞行，俯冲攻击 | 2 |
| **火妖** | 第 5 章起 | 投掷火球，被击中后地面留火 3 秒 | 3 |

#### 精英怪设计

| 精英怪 | 出现章节 | 特殊机制 | HP |
|--------|---------|---------|-----|
| **黑熊精** | 第 2 章 | 会格挡正面攻击，需绕后或等其攻击后反击 | 8 |
| **白骨精化身** | 第 4 章 | 伪装成 NPC 靠近后突然攻击，需火眼金睛识别 | 6 |
| **铁扇公主** | 第 5 章 | 芭蕉扇吹风，将玩家推回起点，需找掩体躲避 | 10 |

#### BOSS 设计

##### BOSS 1：巨灵神（第 2 章）

- **定位：** 教学 BOSS，教会玩家观察攻击模式
- **HP：** 30
- **阶段数：** 1 个阶段
- **攻击模式：**
  1. 举锤下砸 → 前摇明显（1.5 秒），侧闪躲避
  2. 横扫地 → 需要跳跃躲避
- **设计意图：** 让玩家学会"观察→躲避→反击"的基本节奏

##### BOSS 2：白骨精（第 4 章）

- **定位：** 机制 BOSS，教会玩家识别真假
- **HP：** 40
- **阶段数：** 3 个阶段（对应"三变"）
- **攻击模式：**
  1. **第一变（村姑）：** 伪装靠近，被识破后释放毒雾
  2. **第二变（老妇）：** 召唤 3 个分身，只有攻击真身有效
  3. **第三变（老翁）：** 地面出现裂缝，从裂缝中召唤骷髅手抓玩家
- **识别机制：** 使用"火眼金睛"技能（消耗 1 格 MP）可高亮真身
- **设计意图：** 引入"观察细节"的玩法，而非纯战斗

##### BOSS 3：红孩儿（第 5 章前）

- **定位：** 难度提升 BOSS
- **HP：** 45
- **阶段数：** 2 个阶段
- **攻击模式：**
  1. **三昧真火：** 口吐火焰，覆盖前方扇形区域
  2. **火轮追击：** 脚踩风火轮快速冲刺，需要利用场景中的水池躲避
  3. **第二阶段（HP<50%）：** 全身着火，近战攻击会反伤，需用水系道具灭火后再攻击
- **设计意图：** 考验玩家对环境道具的运用

##### BOSS 4：牛魔王（第 5 章）

- **定位：** 最终 BOSS，综合考验
- **HP：** 50
- **阶段数：** 3 个阶段
- **攻击模式：**
  1. **阶段一：** 牛角冲撞 + 踩踏震地（类似巨灵神但更快）
  2. **阶段二：** 变身为巨牛，体型占据半个屏幕，攻击范围极广
  3. **阶段三（HP<30%）：** 狂暴状态，攻击无规律但伤害翻倍，需要变身巨人形态对抗
- **设计意图：** 检验玩家是否掌握了所有已学技能

## 5. 关卡设计

### 整体结构

```
第 1 章：花果山（教学关）
    ↓
第 2 章：大闹天宫（战斗教学）
    ↓
第 3 章：五指山（过渡剧情 + 新机制引入）
    ↓
第 4 章：白骨精三变（识别敌人机制）
    ↓
第 5 章：火焰山（环境挑战 + 最终 BOSS）
```

### 5.1 第 1 章：花果山（教学关）

**主题：** 学习基础操作，感受世界的活力

**关卡结构（预计游玩时间 20-30 分钟）：**

| 小节 | 内容 | 教学目标 |
|------|------|---------|
| 1-1 | 石猴从石头中蹦出，在树林中奔跑 | 左右移动、基础跳跃 |
| 1-2 | 遇到第一只小妖（不会攻击，只是跑来跑去） | 熟悉敌人存在 |
| 1-3 | 获得金箍棒，打木桩练习 | 轻攻击、连击 |
| 1-4 | 小妖开始攻击，需要战斗 | 战斗实战、受伤机制 |
| 1-5 | 需要跳上高低不同的平台 | 跳跃精度练习 |
| 1-6 | 找到瀑布后的水帘洞（隐藏区域） | 探索与发现 |
| BOSS | 混世魔王（简单版，只会跳跃砸地） | 综合实战 |

**场景要素：**
- 翠绿色树林，阳光透过树叶
- 瀑布、溪流、石桥
- 猴子们在背景中嬉戏
- 水帘洞内有宝箱（第一个收集品）

**存档点：** 每小节结束处，共 6 个存档点

---

### 5.2 第 2 章：大闹天宫（战斗教学）

**主题：** 学习进阶战斗技巧，体验都都的巅峰时刻

**关卡结构（预计游玩时间 30-40 分钟）：**

| 小节 | 内容 | 教学目标 |
|------|------|---------|
| 2-1 | 闯入龙宫，水下移动教学 | 水下操控（简化版） |
| 2-2 | 获得金箍棒完整版（之前用的缩小版） | 重攻击、蓄力攻击 |
| 2-3 | 闯入天宫，面对天兵天将 | 连续战斗、连击系统 |
| 2-4 | 被包围，需要突围 | 旋转攻击（群体技能） |
| 2-5 | 与各路神仙交手 | 精英怪战斗 |
| BOSS | 巨灵神 | 教学 BOSS |

**场景要素：**
- 龙宫：蓝色调，珊瑚、气泡、鱼群
- 天宫：金色调，云彩、宫殿、仙鹤
- 背景中可以看到远处的蟠桃园

---

### 5.3 第 3 章：五指山（过渡剧情）

**主题：** 剧情推进，引入同伴系统，节奏放缓

**关卡结构（预计游玩时间 20-25 分钟）：**

| 小节 | 内容 | 教学目标 |
|------|------|---------|
| 3-1 | 闪回：被如来压在五指山下的回忆 | 剧情演出 |
| 3-2 | 五百年后，唐僧揭开封印 | 剧情演出，唐僧加入 |
| 3-3 | 重新学习技能（技能被封印后逐步恢复） | 复习已有技能 |
| 3-4 | 保护唐僧通过危险地带 | 有同伴后的关卡体验 |
| 3-5 | 遇到猪八戒（战斗后加入） | 剧情演出 |
| BOSS | 无 BOSS（本章以剧情和探索为主） | — |

**场景要素：**
- 五指山：灰色调，巨大的手掌形山峰
- 荒凉的古道，偶尔有野花
- 远处可以看到取经路的起点

**本章特殊设计：**
- 节奏较慢，给玩家喘息空间
- 大量对话推进故事
- 解锁唐僧辅助能力（HP 自动回复）

### 5.4 第 4 章：白骨精三变（识别敌人机制）

**主题：** 引入"火眼金睛"机制，观察力挑战

**关卡结构（预计游玩时间 35-45 分钟）：**

| 小节 | 内容 | 教学目标 |
|------|------|---------|
| 4-1 | 进入荒野地带，氛围变得诡异 | 氛围营造 |
| 4-2 | 遇到"村民"求助 → 实为妖怪伪装 | 引入伪装机制 |
| 4-3 | 解锁火眼金睛技能 | 使用技能识别真假 |

- 荒凉的枯树林，雾气弥漫

**火眼金睛机制：**
- 消耗 1 格 MP 激活
- 持续 5 秒，期间妖怪伪装的 NPC 会显示红色轮廓
- 非战斗时也可使用，用于发现隐藏通道

### 5.5 第 5 章：火焰山（环境挑战）

**主题：** 环境危害、限时挑战、最终 BOSS

**关卡结构（预计游玩时间 40-50 分钟）：**

| 小节 | 内容 | 教学目标 |
|------|------|---------|
| 5-1 | 到达火焰山脚下，地面滚烫 | 环境伤害机制引入 |
| 5-2 | 需要寻找芭蕉扇灭火 | 解谜探索 |
| 5-3 | 穿越火焰地带（限时，地面会蔓延火焰） | 限时跑酷 |
| 5-4 | 铁扇公主阻拦（精英怪） | 精英怪战斗 |
| 5-5 | 火焰山内部，岩浆区域 | 高级平台跳跃 |
| 5-6 | 遇到红孩儿（前哨 BOSS） | 中期 BOSS 战 |
| BOSS | 牛魔王 | 最终 BOSS 战 |

**场景要素：**
- 火焰山：红橙色调，火焰、岩浆、黑色岩石
- 背景中火焰不断蔓延
- 偶尔有火焰旋风经过

**环境机制：**
- **热浪伤害：** 在没有遮阴处停留超过 5 秒会受到持续伤害
- **火焰地面：** 部分地面有火，踩上去受伤
- **冷却点：** 散布在关卡中的水潭，可暂时免疫热浪
- **芭蕉扇：** 关卡道具，可对特定区域吹风灭火（限时）

---

### 关卡通用设计原则

1. **节奏曲线：** 每章遵循"简单→中等→困难→喘息→BOSS"的节奏
2. **存档点密度：** 平均每 3-5 分钟游戏路程一个存档点
3. **隐藏区域：** 每关至少 2 个隐藏区域（需要仔细观察或特殊能力到达）
4. **回头路设计：** 获得新能力后可以回到之前的关卡解锁新路径（银河恶魔城轻度元素）
5. **难度可调：** 每个存档点可切换"简单/普通"难度

## 6. 操作系统

### 6.1 平板触屏控制

采用虚拟摇杆 + 按钮布局，适配横屏模式：

```
┌─────────────────────────────────────────────┐
│                                             │
│                                             │
│           [暂停按钮]                         │
│                                             │
│                                      [B]    │
│  ┌───┐                              [A]     │
│  │ ↑ │                           [冲刺]     │
│  │   │                              [C]    │
│  │← →│                                     │
│  │ ↓ │                                     │
│  └───┘                                     │
│ [摇杆]                                      │
└─────────────────────────────────────────────┘
```

**按钮说明：**

| 按钮 | 位置 | 功能 |
|------|------|------|
| **虚拟摇杆** | 左下角 | 移动方向 |
| **A 按钮** | 右下角 | 跳跃（长按 = 筋斗云） |
| **B 按钮** | A 按钮上方 | 攻击 |
| **C 按钮** | A 按钮左侧 | 冲刺/闪避 |
| **技能按钮** | B 按钮右侧 | 变身 / 火眼金睛 |
| **暂停** | 左上角 | 暂停菜单 |

**触屏优化要点：**
- 摇杆区域大小可调节（设置中调整）
- 按钮支持半透明（不遮挡视野）
- 支持自定义按钮位置
- 攻击按钮支持滑动操作（上滑 = 重攻击）
- 误触保护：按钮间留有间距，按下后有 0.1 秒防抖

### 6.2 Xbox 手柄控制

| 按键 | 功能 |
|------|------|
| **左摇杆 / 十字键** | 移动 |
| **A 键** | 跳跃（长按 = 筋斗云） |
| **X 键** | 轻攻击 |
| **Y 键** | 重攻击（蓄力） |
| **B 键** | 冲刺/闪避 |
| **RB 键** | 变身 |
| **LB 键** | 火眼金睛 |
| **Start** | 暂停 |
| **右摇杆** | 未使用（预留） |

**手柄优化要点：**
- 支持按键重映射
- 振动反馈：受击、重攻击命中、BOSS 登场时触发
- 同时支持 Xbox 有线和无线手柄

### 6.3 双端统一逻辑

- 游戏内部使用统一的输入抽象层，不区分触屏/手柄
- 同一存档可在平板和 Xbox 间切换（云存档，如果平台支持）
- 暂停菜单中显示当前操控方式对应的按键提示

## 7. 美术方向

### 7.1 像素风格指南

**基础规格：**
- **基础网格：** 32×32 像素（角色和道具）
- **地图块（Tile）：** 32×32 像素
- **分辨率：** 游戏内部分辨率 480×270（16:9），按整数倍放大到目标屏幕
- **放大倍率：** 平板上 4-5 倍，Xbox 1080p 下 4 倍

**风格原则：**
- **清晰可读：** 角色和背景色彩对比明显，玩家一眼能分辨前景和背景
- **有限调色板：** 每个场景使用 16-24 色调色板，保持视觉统一
- **避免抖动：** 不使用亚像素动画，所有移动以整像素为单位
- **参考风格：** Celeste（精致感） + 东方题材色彩

## 8. 音效音乐

### 8.1 音乐方向

**整体风格：** 芯片音乐（Chiptune） + 中国民族乐器采样（笛子、古筝、二胡）

| 场景类型 | 音乐风格 | 乐器重点 | 情绪 |
|---------|---------|---------|------|
| **主菜单** | 悠扬的笛子旋律 + 轻快节拍 | 笛子 + 8-bit 鼓点 | 期待、冒险 |
| **探索关卡** | 轻快的 8-bit 旋律 | 古筝 + Chiptune | 轻松、前进感 |
| **战斗** | 快节奏鼓点 + 激昂旋律 | 鼓 + 电吉他音色 | 紧张、热血 |
| **BOSS 战** | 史诗感 + 快速节奏 | 二胡 + 重金属节拍 | 压迫感、挑战 |
| **剧情/悲伤** | 缓慢、抒情 | 古筝独奏 + 环境音 | 感伤、沉思 |
| **胜利** | 欢快、庆祝感 | 全乐器合奏 | 成就、喜悦 |

**音乐技术要点：**
- 使用循环音乐（Loop），每首 1-2 分钟循环
- BOSS 战音乐有"阶段切换"变奏（HP 低于 50% 时加入更激烈的层次）
- 总曲目数：8-12 首（含变奏）

### 8.2 音效设计

#### 角色音效

| 音效 | 描述 | 时长 |
|------|------|------|
| 跳跃 | 轻快的"嗖"声 | 0.2s |

| 重攻击 | 蓄力"嗡"声 + 猛烈挥击 | 0.8s |

| 冲刺 | 快速移动的"嗖嗖"声 | 0.3s |
| 变身 | 光芒闪烁 + 变身音效 | 1.0s |
| 筋斗云 | 云朵升起的柔和音效 | 0.5s |

#### 环境音效

| 音效 | 适用场景 |
|------|---------|
| 鸟鸣虫叫 | 花果山 |

| 风声 | 天宫、山顶 |

### 8.3 音频资源建议

- **音乐制作：** 使用 FamiTracker 或 LMMS 制作 8-bit 风格音乐
- **音效制作：** 使用 Bfxr 或 sfxr 生成 8-bit 音效
- **免费资源：** 可参考 freesound.org、OpenGameArt.org
- **格式：** 音乐使用 OGG Vorbis，音效使用 WAV（短音效）或 OGG（长音效）
- **音量分层：** 音乐 60%、音效 80%、环境音 40%（可在设置中调节）

## 9. 开发路线图

### 整体规划

作为初学者独立开发者，采用**渐进式开发**策略。先把最小可玩版本做出来，再逐步完善。

```
MVP（最小可玩版本）     → 3-4 个月
Alpha（内容完整版）      → 4-5 个月
Beta（打磨修复版）       → 3-4 个月
Release（正式发布）      → 1-2 个月
─────────────────────────────────────
总计：约 12-16 个月
```

### 初学者关键建议

1. **先做 MVP：** 不要一开始就想着做完美版本，先让角色能跑能跳能打怪
2. **每周小目标：** 每周完成一个小功能，不要定太大的目标
3. **善用现成资源：** OpenGameArt、itch.io 上的免费素材可以先用着，后面再替换
4. **加入社区：** 加入游戏开发社区（如 indienova、GameDev.net），遇到问题有人帮
5. **定期构建：** 每周至少打包一次可执行文件，确保游戏始终能运行
6. **控制范围：** 如果感觉做不完，优先砍内容（减少关卡），不要砍核心系统
7. **版本管理：** 从第一天开始使用 Git，提交到 GitHub
8. **记录进度：** 每周截图/录屏记录进度，既是动力也是调试参考

### B. 术语表

| 术语 | 解释 |
|------|------|
| **Hit Stop** | 击中瞬间的短暂停顿，增强打击感 |
| **i-frame** | 无敌帧，受伤后的短暂无敌时间 |
| **Tile** | 地图块，用于拼接关卡地图的基础图片单元 |
| **Sprite** | 精灵图，游戏中角色和物体的图像 |
| **Hitbox** | 碰撞判定框，决定攻击/碰撞是否生效的区域 |
| **Hurtbox** | 受击判定框，角色可被攻击到的区域 |
| **Coyote Time** | 土狼时间，离开平台边缘后仍可跳跃的宽容时间（建议 0.1 秒） |
| **Jump Buffer** | 跳跃缓冲，落地前按跳跃键会在落地瞬间自动跳跃（建议 0.1 秒） |

### C. 风险与应对

| 风险 | 影响 | 应对策略 |
|------|------|---------|
| 范围膨胀 | 无法按时完成 | 严格控制 5 章内容，不加新章节 |
| 美术效率低 | 进度延迟 | 先用简单占位图，后期统一替换 |
| 手柄适配困难 | 影响 Xbox 体验 | 用 Unity New Input System 统一抽象触屏与手柄输入 |
| 平板性能不足 | 卡顿影响体验 | 减少粒子数量，降低分辨率放大倍率 |
| 半途放弃 | 项目烂尾 | 加入开发社区，找伙伴互相监督 |
